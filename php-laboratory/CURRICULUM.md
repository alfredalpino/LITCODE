# PHP Curriculum

Derived from: roadmap.sh PHP roadmap (language track only — PHP manual / PHP: The Right Way outline).

| # | Module | Planned focus |
| --- | --- | --- |
| 00 | Environment & the PHP Toolchain | Installing PHP, the built-in server php -S, Composer, php.ini, and the request lifecycle. |
| 01 | Syntax, Values & Types | Variables, scalar types, type juggling, constants, and strict_types declare. |
| 02 | Control Flow & Functions | if/switch/match, loops, function definitions, type declarations, and default/variadic args. |
| 03 | Strings & Arrays | String functions, indexed vs associative arrays, the array_* family, and spread/destructuring. |
| 04 | Functions, Closures & Callables | Closures, arrow functions, use captures, first-class callable syntax, and named arguments. |
| 05 | OOP: Classes & Objects | Classes, visibility, static members, constructor property promotion, and readonly properties. |
| 06 | Interfaces, Traits & Enums | Interfaces, abstract classes, traits and conflict resolution, and backed enums. |
| 07 | Error Handling | Exceptions, try/catch/finally, the Throwable hierarchy, and errors vs exceptions. |
| 08 | Composer & Namespaces | Namespaces, PSR-4 autoloading, composer.json, and semantic dependency versions. |
| 09 | Testing & Tooling | PHPUnit assertions, data providers, the red-green loop, and a PHPStan/static-analysis overview. |

All modules are currently **scaffold** status. See each module's `STATUS.md`.
