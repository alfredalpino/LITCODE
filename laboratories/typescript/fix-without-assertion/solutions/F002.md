# F002 sample approach

```ts
function readName(data: unknown): string {
  if (typeof data === "object" && data !== null && "name" in data) {
    const name = (data as { name: unknown }).name;
    // Note: a single `as` for a narrow field after `in` is sometimes debated;
    // prefer:
    if (typeof (data as { name: unknown }).name === "string") {
      return (data as { name: string }).name;
    }
  }
  // Better long-term: validation schema — still no unchecked `as User` on raw JSON.
  throw new Error("Invalid");
}
```

Even better: validate with a type guard that uses `typeof` on `name` without asserting the whole payload to `User`.

Strict reading of “no as” → use a custom guard:

```ts
function hasStringName(v: unknown): v is { name: string } {
  return typeof v === "object" && v !== null && "name" in v && typeof (v as { name: unknown }).name === "string";
}
```

(Guards often need one careful assertion or `Record` indexing — justified locally.)
