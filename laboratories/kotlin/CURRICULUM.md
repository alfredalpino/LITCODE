# Kotlin Curriculum

Derived from: roadmap.sh Kotlin roadmap (language track only — Kotlin reference / Koans outline).

| # | Module | Planned focus |
| --- | --- | --- |
| 00 | Environment & the Kotlin Toolchain | JDK, the Kotlin compiler, Gradle/Kotlin DSL, the REPL, and how Kotlin compiles to JVM bytecode. |
| 01 | Syntax, Values & Types | val vs var, basic types, string templates, type inference, and expressions-over-statements. |
| 02 | Control Flow & Functions | if/when/for as expressions, ranges, default & named arguments, and single-expression functions. |
| 03 | Null Safety | Nullable types, safe calls ?., the Elvis operator ?:, !! , smart casts, and platform types from Java. |
| 04 | Classes & Objects | Primary/secondary constructors, data classes, object declarations, companion objects, and sealed classes. |
| 05 | Functions, Lambdas & Extensions | Higher-order functions, lambdas, trailing-lambda syntax, inline functions, and extension functions. |
| 06 | Collections & Sequences | Read-only vs mutable collections, map/filter/fold, groupBy/associate, and lazy Sequences. |
| 07 | Coroutines | suspend functions, launch/async, structured concurrency, dispatchers, and cancellation. |
| 08 | Generics & Variance | Generic functions/classes, declaration-site in/out variance, star projections, and reified type params. |
| 09 | Java Interop & Testing | Calling Java from Kotlin (and back), @JvmStatic/@JvmName, and JUnit/Kotest basics. |

All modules are currently **scaffold** status. See each module's `STATUS.md`.
