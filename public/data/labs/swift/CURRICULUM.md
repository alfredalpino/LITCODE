# Swift Curriculum

Derived from: roadmap.sh Swift roadmap (language track only — The Swift Programming Language / Swift.org outline).

| # | Module | Planned focus |
| --- | --- | --- |
| 00 | Environment & the Swift Toolchain | Installing the Swift toolchain, swift REPL, Swift Package Manager, and how swiftc compiles a module. |
| 01 | Syntax, Values & Types | let vs var, fundamental types, type inference, string interpolation, and tuples. |
| 02 | Control Flow, Functions & Closures | if/guard/switch with pattern matching, for-in, functions, closures, and trailing-closure syntax. |
| 03 | Optionals | Optional binding (if let/guard let), optional chaining, nil-coalescing ??, and the risks of force unwrap. |
| 04 | Structs, Classes & Enums | Value vs reference semantics, memberwise initializers, enums with associated & raw values, and mutating methods. |
| 05 | Protocols & Extensions | Protocol requirements, protocol-oriented programming, default implementations, and conditional conformances. |
| 06 | Collections & Generics | Array/Dictionary/Set, generic functions & types, associated types, and where clauses. |
| 07 | Error Handling | throws/try/catch, typed Result, rethrows, defer, and try? vs try!. |
| 08 | Memory & ARC | Automatic Reference Counting, strong/weak/unowned references, and breaking retain cycles in closures. |
| 09 | Concurrency & Testing | async/await, Task, actors and data isolation, and XCTest basics. |

All modules are currently **scaffold** status. See each module's `STATUS.md`.
