# Kotlin Laboratory

**Status:** scaffold (topic skeletons only — 0 ready modules)

Kotlin language fundamentals on the JVM: null safety, classes, functional idioms, collections, and coroutines. Android UI and Jetpack are intentionally out of scope for this language lab.

## Planned curriculum

- 00 — Environment & the Kotlin Toolchain
- 01 — Syntax, Values & Types
- 02 — Control Flow & Functions
- 03 — Null Safety
- 04 — Classes & Objects
- 05 — Functions, Lambdas & Extensions
- 06 — Collections & Sequences
- 07 — Coroutines
- 08 — Generics & Variance
- 09 — Java Interop & Testing
