# Progress Tracker

Honest tracking beats optimistic tracking. Update this file as you work.

---

## How to use

1. After each session, update **Session log**.
2. Mark concepts/exercises in the tables.
3. Record prediction accuracy (correct / attempted).
4. Add weak concepts immediately — do not wait.
5. Schedule spaced reviews (Day 1 / 3 / 7 / 14 / 30).
