# C# Curriculum

Derived from: roadmap.sh C# / .NET roadmap (language track only — Microsoft C# guide outline).

| # | Module | Planned focus |
| --- | --- | --- |
| 00 | Environment & the .NET Toolchain | Installing the .NET SDK, dotnet new/run, the csproj project model, and top-level statements. |
| 01 | Syntax, Values & Types | var, value vs reference types, nullable value types, boxing, and target-typed new. |
| 02 | Control Flow & Methods | if/switch expressions, pattern matching, loops, methods, and ref/out/params parameters. |
| 03 | Classes & Objects | Classes, properties, auto-properties, records, structs, and object initializers. |
| 04 | Interfaces & Inheritance | Interfaces, abstract classes, virtual/override, sealed, and default interface methods. |
| 05 | Collections & Generics | List/Dictionary/HashSet, generic types & methods, constraints, and IEnumerable. |
| 06 | LINQ | Query vs method syntax, deferred execution, projection/filtering/grouping, and IQueryable basics. |
| 07 | Async & Await | Task/Task<T>, async/await, ConfigureAwait, cancellation tokens, and common deadlock traps. |
| 08 | Error Handling & Resources | Exceptions, try/catch/finally, exception filters, using/IDisposable, and nullable reference types. |
| 09 | Testing & Tooling | xUnit/NUnit basics, the Arrange-Act-Assert loop, dotnet test, and analyzers. |

All modules are currently **scaffold** status. See each module's `STATUS.md`.
