# Spaced Review

After completing a module, schedule:

| Offset | Action |
|---|---|
| Day 1 | Predict + explain |
| Day 3 | Debug + classify |
| Day 7 | Teach-back + re-predict |
| Day 14 | Implement a tiny related abstraction |
| Day 30 | Mixed review with newer modules |

Use each module’s `review.md`. Log dates in `PROGRESS.md`.

**Avoid** rereading notes as your primary review method.
