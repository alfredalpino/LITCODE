# Swift Laboratory

**Status:** scaffold (topic skeletons only — 0 ready modules)

Swift language fundamentals: value types, optionals, protocols, generics, and structured concurrency. SwiftUI and app lifecycle are intentionally out of scope for this language lab.

## Planned curriculum

- 00 — Environment & the Swift Toolchain
- 01 — Syntax, Values & Types
- 02 — Control Flow, Functions & Closures
- 03 — Optionals
- 04 — Structs, Classes & Enums
- 05 — Protocols & Extensions
- 06 — Collections & Generics
- 07 — Error Handling
- 08 — Memory & ARC
- 09 — Concurrency & Testing
