# Java Curriculum

Derived from: roadmap.sh/java (modern Java Developer roadmap) — basics, OOP, collections, exceptions, functional Java, concurrency, JVM. Frameworks (Spring) are out of scope here.

| # | Module | Planned focus |
| --- | --- | --- |
| 00 | Java Ecosystem & the JVM | JDK vs JRE vs JVM, javac → bytecode → JIT, the lifecycle of a program, main method, classpath. |
| 01 | Basic Syntax, Variables & Types | Primitives vs references, var, autoboxing, type casting, literals, String immutability. (after ecosystem-jvm) |
| 02 | Control Flow, Loops & Methods | if/switch (incl. switch expressions), loops, method declaration, overloading, varargs, pass-by-value. |
| 03 | Arrays, Strings & Math | Array creation & iteration, String vs StringBuilder, common String methods, Math utilities. |
| 04 | Object-Oriented Programming Basics | Classes/objects, fields & methods, constructors, access modifiers, static keyword, packages. |
| 05 | Encapsulation, Inheritance & Polymorphism | Getters/setters, extends, super, method overriding, dynamic dispatch, final, Object methods. (after oop-classes-objects) |
| 06 | Interfaces & Abstract Classes | Abstract vs interface, default methods, multiple interface inheritance, enums, records. |
| 07 | Exception Handling | Checked vs unchecked, try/catch/finally, try-with-resources, throw/throws, custom exceptions. |
| 08 | Collections Framework & Generics | List/Set/Map/Queue, ArrayList vs LinkedList, iterators, generic types & bounded wildcards. (after oop-classes-objects) |
| 09 | Functional Java (Lambdas & Streams) | Functional interfaces, lambdas & method references, the Stream pipeline, Optional, collectors. |
| 10 | Concurrency & Threads | Thread/Runnable, synchronization, the Java Memory Model overview, ExecutorService, virtual threads. |
| 11 | I/O, Files & Modules | java.io vs java.nio, reading/writing files, serialization overview, the module system (JPMS) intro. |

All modules are currently **scaffold** status. See each module's `STATUS.md`.
