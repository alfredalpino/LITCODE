# LITCODE — Brand Identity

## Essence

**Mastery formed under experiment.**  
LITCODE is the place you predict, run, break, and explain until understanding holds — then transfer that skill to interview problems.

## Name construction

| Part | Meaning |
|---|---|
| **Loop** | The pedagogy cycle (predict → run → break → explain); also a nod to runtime/event-loop literacy |
| **form** | Skill shaped by deliberate practice; SaaS-familiar compound (without copying any existing -form product’s look) |

**Pronunciation:** LOOP-form  
**Plural / possessive:** LITCODE / LITCODE’s  
**Avoid:** “SDE Lab,” “Laboratory Studio,” “LF” as primary brand, “LeetCode for X”

## Personality in design

| Trait | Visual / UX implication |
|---|---|
| Precise | Tight spacing, clear hierarchy, monospace for code/truth |
| Experimental | Motion used for state change (run, break, pass) — not decoration |
| Honest | Status badges (scaffold / ready / judged) as first-class chrome |
| Rigorous | Technical density without clutter; one job per section |
| Calm confidence | Deep slate surfaces; one accent; no neon purple glow |
| Transfer-minded | Cross-links lab ↔ challenge visible in product language |

## Design language (product UX direction)

Aligned with elite developer-product standards — originality required:

- **Composition:** Lab workbench first — not a dashboard of vanity stats  
- **Surfaces:** Deep slate / charcoal; subtle gradients or grid atmosphere OK; avoid flat white “AI SaaS” default  
- **Accent:** Signal teal for run/success/primary CTA — single accent discipline  
- **Type:** Expressive but disciplined sans for UI; mono for code — see `typography.md`  
- **Imagery:** Real editor / console / experiment context — not stock graduation caps or abstract brains  
- **Motion:** 2–3 intentional motions (pane enter, run flash, mastery tick) — no particle noise  

### Explicitly avoid (product design rules)

1. Purple-on-white / purple-to-indigo AI cliché  
2. Warm cream + terracotta + serif “editorial” cliché  
3. Broadsheet hairline / newspaper column cliché  
4. Generic braces / terminal / AI-brain / graduation-cap logos unless genuinely differentiated (our mark is a **broken loop**, not braces)

## Logo system summary

- **Mark:** Open geometric loop (gap = break / experiment)  
- **Wordmark:** “LITCODE” in geometric sans  
- **Lockups:** Mark + wordmark horizontal; mark-only for favicon / nav
