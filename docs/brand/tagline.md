# LITCODE — Tagline & Motto

## Options compared

| Option | Line | Strength | Weakness | Verdict |
|---|---|---|---|---|
| A | Predict. Run. Break. Prove. | Encodes pedagogy; rhythmic; unique | Slightly instructional | **Primary tagline** |
| B | Run the experiment. Keep the skill. | Warm; retention-framed | Softer; less interview signal | Secondary / ads |
| C | Prove what you think you know. | Strategic; sharp; from product thesis | Longer for locked UI chrome | **Motto** |
| D | Mastery by experiment. | Compact category claim | Generic “mastery” risk | Supporting |
| E | Stop consuming. Start breaking. | Provocative; anti-tutorial | “Breaking” alone can sound vandal | Occasional campaign |
| F | Form skill under load. | Name-adjacent (“form”); interview heat | Slightly abstract | Supporting |
| G | Learn to code by doing. | Clear | Generic; rejected by strategy | **Rejected** |
| H | The LeetCode alternative that teaches. | SEO bait | Defines us by competitor | **Rejected** |

## Final selection

| Role | Line |
|---|---|
| **Tagline** | Predict. Run. Break. Prove. |
| **Motto** | Prove what you think you know. |
| **Secondary** | Run the experiment. Keep the skill. |

## Usage

- **Tagline:** Under logo on marketing, README hero, App Store–style one-liners, `metadata.description` lead-in  
- **Motto:** Closing line, profile defaults, manifesto moments  
- **Secondary:** Onboarding, empty states, email subjects  

Never pair tagline and motto in the same tight lockup — pick one dominant line per surface.
