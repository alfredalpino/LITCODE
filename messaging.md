# LITCODE — Messaging Hierarchy

## Mission

Build the practice-first laboratory where engineers form durable language skill and transfer it to interview problems through experiments they can run, break, and explain.

## Vision

A generation of engineers who stop confusing tutorial familiarity with mastery — and can prove what they know under real constraints.

## Positioning

For self-taught and early-career engineers, LITCODE is a practice-first developer laboratory that turns language mastery into interview-ready skill through predict → run → break → explain experiments — unlike grind platforms or course libraries — because it productizes laboratory pedagogy and curated skill transfer, not catalog scale.

## Value proposition

**Run real experiments on JS, TS, and Python. Prove patterns on judged challenges. See what you actually know — before the interview asks.**

## Primary message

Stop consuming tutorials. Run experiments. Prove what you think you know.

## Secondary messages

1. Language labs and interview DSA share one shell — pedagogy first, catalog second.  
2. Honesty is a feature: scaffolds, judged sets, and external links are labeled.  
3. The loop is the product: predict → run → break → explain → build.  
4. Depth of ready modules and judged problems beats index length.  
5. Built for engineers who want transfer, not theater.

## Tagline

**Predict. Run. Break. Prove.**

## Motto

**Prove what you think you know.**

## Elevator (15s)

LITCODE is a developer laboratory for language mastery and interview practice. You predict, run, and break code until the concept sticks — then transfer it to curated judged challenges. Not another 10k-problem list.

## Elevator (30s)

Most interview prep tools optimize for volume. LITCODE optimizes for experiments. Language labs in JavaScript, TypeScript, and Python teach how runtimes actually behave. Interview challenges are curated and judged — mapped to patterns you practiced — so progress is evidence, not a fake acceptance rate. If you’re done binge-watching tutorials, this is the workbench.
