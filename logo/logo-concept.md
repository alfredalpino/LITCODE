# LITCODE — Logo Concept

## Idea

A **closed practice loop with one deliberate gap** — the break.

- The ring = predict → run → explain continuity  
- The gap = break-the-code / falsify-your-assumption  
- Geometry stays simple enough for 16×16 favicon  

No braces `{}`, no terminal prompt, no brain, no mortarboard.

## Construction

- Outer form: continuous stroke on a circular path (~270–300° arc)  
- Terminals: squared or slightly rounded caps for technical feel  
- Optional inner tick at the gap’s leading edge = “run head” / progress  
- Clear space: ≥ ¼ mark diameter on all sides  
- Minimum size: 16px mark-only; 88px wide for wordmark lockup  

## Variants

| File | Use |
|---|---|
| `logo.svg` | Primary lockup (mark + wordmark) |
| `logo-mark.svg` | App icon, nav, favicon source |
| `logo-wordmark.svg` | Wordmark alone for wide headers |

## Color

- Default: signal teal `#2DD4A8` on transparent  
- On dark UI: teal mark + chalk `#E8EEF5` wordmark  
- Mono dark: chalk on void  
- Mono light: slate `#0B0F14` on white  

## Don’t

- Add gradients, glow, or multi-color fills to the mark  
- Stretch the loop into an oval for “style”  
- Place the mark inside a rounded app-store card with drop shadow as the *brand definition* (product icons may need a plate later — keep plate neutral slate)
